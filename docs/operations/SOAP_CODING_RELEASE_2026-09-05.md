# SOAP, coding, registration, and admission release

## Scope

Daniel requested the remaining annotated outpatient medical-form changes and deployment of the combined update on 5 September 2026. This release includes the pending dashboard, registration, SATUSEHAT administrative-gender, and physician-signed admission changes from the same working session. It does not activate warehouse, BPJS, SATUSEHAT submission, or other live clinical integrations.

The medical form uses explicit Subjective, Objective, Assessment, and Plan labels. Assessment includes diagnosis free text, one primary ICD-10 selection, and secondary selections. Plan includes ICD-9-CM procedure selections. Selection is explicit; the application does not infer diagnoses or procedures from narrative text. Codes and descriptions persist in draft and immutable final document versions and remain visible after reload and in history.

Terminology lookup uses the [WHO ICD-10 2010 browser](https://icd.who.int/browse10/2010/en) and [NLM Clinical Tables ICD-9-CM procedures](https://clinicaltables.nlm.nih.gov/apidoc/icd9cm_sg/v3/doc.html). WHO ICD-10 is not substituted with ICD-10-CM. Searches send only the entered lookup query, not the patient's record or SOAP narrative, to the fixed provider. This hosted application remains synthetic-only. Search results require human selection; the server validates code/display pairs against provider responses and caches verified pairs. External-provider outages produce an unavailable response rather than fabricated codes. This is not an offline terminology catalog or certified coding engine.

Older documents lacking coded fields remain readable and compatible. New structured submissions validate diagnosis text, primary and secondary selections, duplicate codes, and procedure entries. Final records cannot be rewritten through ordinary draft saves.
