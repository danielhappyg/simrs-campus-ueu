# Vendor SIMRS 3.0 Assessment Plan

Assessment target: `https://simrs.universitasesaunggul.com/`

Assessment mode: authorized, non-destructive, evidence-based review. No credentials are recorded in this workspace.

## Evidence labels

- **Observed:** directly visible in the live application or its public HTTP response.
- **Vendor-stated:** claimed in Sahabat Mediacom material but not independently demonstrated.
- **Repository-confirmed:** supported by files in the local workspace.
- **Inferred:** plausible technical interpretation that still requires vendor or infrastructure evidence.
- **Unverified:** requested evidence is not yet available.

## Workstreams

1. Public surface and authentication boundary.
2. Authenticated module, menu, role, and permission inventory.
3. Representative hospital workflows and handoffs.
4. Data entities, integrations, reporting, and auditability.
5. Architecture, deployment, backup, recovery, monitoring, and support.
6. Privacy, security, regulatory, accessibility, and patient-safety controls.
7. Vendor dependency, ownership, licensing, SLA, portability, and exit risk.
8. Findings, target model, priorities, and phased roadmap.

## Safety boundary

The walkthrough will not create or edit patients, visits, clinical records, prescriptions, claims, bills, users, permissions, master data, or configuration. It will not submit forms, resend integrations, export personal data, run load tests, attempt exploitation, or perform credential attacks without a separate written authorization and rules of engagement.
