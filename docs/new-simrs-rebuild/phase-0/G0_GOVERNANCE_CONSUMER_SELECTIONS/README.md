# Governance consumer selections

This directory is reserved for immutable consumer-selection artifacts created by the canonical selector after every required Gate-B authority and technical precondition passes. This README is documentation only; it is not a selection and has no authority effect.

Selections must not be created, copied, edited, or inferred manually from a candidate, test result, review, journal, receipt, or file presence. A retained candidate remains non-authoritative until a separately approved, externally attestable operation is validated and completed by the selector.

No selection is authorized while the external product-owner and independent-review attestation trust store is unprovisioned. Canonical activation and pointer mutation therefore remain blocked.
