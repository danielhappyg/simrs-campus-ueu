# Governance-v2 activation decisions

This directory is reserved for immutable, approved single-operation Gate-B decision artifacts. This README, a draft, a retained candidate, a technical preflight, or a review record is not an operation decision and has no authority effect.

An approved decision must be created only after the closed contract is satisfied and must bind the exact operation, environment, actor, source decision, conditions, expiry, prior state, candidate or held target, technical evidence, and required external attestations. Repository writers must not manufacture approval by copying an identity, message, hash, or review into this directory.

The external product-owner and independent-review attestation trust store is not provisioned. No approved activation decision may be published, and canonical Gate-B activation remains blocked.
