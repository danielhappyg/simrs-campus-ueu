# Module / Vertical-Slice Definition of Done

- [ ] Approved requirements and evidence links exist.
- [ ] Actors, permissions and server-side negative tests are complete.
- [ ] Patient/encounter context and state transitions are unambiguous.
- [ ] Happy, invalid, duplicate, cancellation, correction, reversal and concurrency cases are tested.
- [ ] Clinical, stock, financial, claim and report postings reconcile where applicable.
- [ ] Audit events include actor, time, subject, reason and before/after state.
- [ ] External messages have idempotency, retry, failure and reconciliation behavior.
- [ ] Synthetic data and environment controls are verified.
- [ ] Automated unit, component, integration and end-to-end tests pass.
- [ ] Performance, accessibility and security checks meet the slice targets.
- [ ] User, admin, support and recovery documentation is updated.
- [ ] Database migration, deployment and rollback are tested.
- [ ] Monitoring and alerts exist for critical paths/background work.
- [ ] Product owner and affected business owner accept the UAT evidence.
- [ ] Parity defects and post-parity improvements are recorded separately.
